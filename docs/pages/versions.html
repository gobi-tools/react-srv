React Support

React Srv can work with different versions of React, starting from v18.0.0 up until the latest.

React Srv also requires the react and react-dom packages be installed, which are used for building (transforming JSX into HTML and bundleing JS).

They are defined as peer dependencies, so NPM will choose the most suitable option, but if you want to have precise control over the version you can install each manually:

npm i react@version
npm i react-dom@version

# optionally install the associated types
npm i @types/react@version --save-dev
npm i @types/react-dom@version --save-dev

Careful

Make sure the react and react-dom versions are identical.

In dev mode the local version of React is sufficient. For production builds that's not the case anymore. By default, React Srv uses esm.sh as a CDN to serve the latest React version.

You can change that by modifying the config file or leave as is if you're happy with the default configuration.

export default {
  Document,
  ...other options
  reactLocation: 'https://esm.sh',
  reactVersion: 'latest', // or 18.3.0, for example
}

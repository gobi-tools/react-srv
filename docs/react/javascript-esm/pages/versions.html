Support

React Srv can work with different versions of React, starting from 18.0.0 up until the latest.

Furthermore, React Srv doesn't bundle React in any of the JS scripts it outputs, either in SSR or SSG mode.

It instead references it from a CDN, esm.sh by default. You can change this in the config:

By doing this we ensure we serve as little JS as possible to hydrate. React itself will usually only get loaded once, for the first page that a user might see. After that it should be cached by the browser.

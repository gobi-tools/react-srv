# Documentation

This section serves both as the official project documentation source (available [here](https://gobi-tools.github.io/react-srv/)) and as an example of how to achieve server side genration ([SSG](https://developer.mozilla.org/en-US/docs/Glossary/SSG)).

You first need to install dependencies 

```bash
npm i
```

Will will allow you to generate the docs:

```bash
npm run docs
```

Configuration happens in [react-srv.config.ts](https://github.com/gobi-tools/react-srv/blob/main/pages/src/react-srv.config.ts).

If you would like to look at [SSR](https://developer.mozilla.org/en-US/docs/Glossary/SSR) demos, go to [this section](https://github.com/gobi-tools/react-srv/tree/main/demos).
